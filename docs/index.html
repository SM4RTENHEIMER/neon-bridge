Neon Colour Chart

Reloop's official MIDI map does not describe the RGB pads — only the five small status LEDs. This is the protocol, measured on the hardware.

9d  nn  vv
│   │   └─ velocity = (R<<4) | (G<<2) | B  — each channel 0-3
│   └───── note number for the pad in the active mode
└──────── 97 98 99 9A = deck A B C D

Colour lives in the velocity byte

Not as a palette index, but as three fields of two bits each. That is why 127 produces white: the low six bits are all set.

Full brightness means at least one channel sits at 3. Orange R3 G1 B0 is exactly as bright as pure red — the two bits of green make it orange, not dimmer.

Pad addresses

Which note a pad sends and listens on depends on the performance mode selected on the unit. Eight consecutive notes per bank, pad 1 first.

LayerSamplerSlicerHot CueHot Loop
1st00-0708-0F10-1718-1F
1st + shift20-2728-2F30-3738-3F
2nd + shift40-4748-4F50-5758-5F
2nd60-6768-6F70-7778-7F

Deck comes from the status byte: 97 A, 98 B, 99 C, 9A D. So Hot Cue pad 3 on deck B is 98 12 vv.

The five status LEDs

The small elongated indicators above each pad in the top row, below each pad in the bottom row. Five notes per pad, all on channel 9B, with colours wired in hardware. Velocity controls brightness only.
